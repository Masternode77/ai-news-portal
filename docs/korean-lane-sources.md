# Korean infrastructure brief: source and rights record

The `/ko/` lane is a manually reviewed, text-only set of short decision-support cards. It is not a live scraper and does not turn a discovered government item into a public page automatically. Each record in `src/data/korea-briefs.json` is pinned to one source URL, one publication date, one manual approval, and one rights-review expiry date.

## Publication rule

- A summary is published only when the same item URL carries a public-use notice that permits the derivative text use. The current approved records each say that text may be used under KOGL Type 1 with attribution.
- Photos, illustrations, video and attachments are excluded. Policy Briefing warns that it commonly does not own those media rights.
- Missing item-level evidence, a future publication date, an expired review, or a non-text scope blocks the record.
- Unknown, non-commercial (KOGL Type 2 or 4), and no-derivatives (KOGL Type 3 or 4) licences produce a link-only record with no summary.
- Older items are labelled `정책 아카이브` so readers do not mistake them for breaking news.
