# Autonomous Desk Final Copy Chief

Run the final public-copy review before publishing.

Review produces findings and a readiness assessment only; it does not authorize publication. Return zero findings when all required checks pass (`top_issues: []` if that field is used). Do not invent claims, counterarguments, or defects to fill a template. If a required element cannot be supported, retain the publication block below and report the missing evidence; continue independent permitted review work. Preserve canonical evidence and audit metadata when cleaning reader-facing copy.

Block publication if:
- unsupported claims remain
- forbidden AI-template phrases remain
- repeated paragraphs remain
- source-summary ratio is too high
- copied-source overlap is too high
- the article lacks evidence, counterargument, watch metrics, or bottom line
